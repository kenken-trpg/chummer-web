Chummer Web 利用マニュアル

ブラウザだけで動く Shadowrun 5th Edition のキャラクター作成ツールです。このページは どの画面で何をするかを、実際の画面のスクリーンショットと一緒に順に説明します。 ルールそのものの解説ではありません（出典は画面の「?」と各項目の SR5 p.xx 表記を参照）。

掲載している画面は、このマニュアル用に作ったオークのサンプル「カイト」のものです。 本文と画面は v0.5.2（2026年10月16日撮影）の表記に合わせています。 数値は操作説明用のサンプルで、作成完了済みのキャラクターではありません。

画面の見取り図

画面は上からツールバー・タブの列・作業領域の 3 段で、 右（狭い画面では下）にサイドバーが常に出ています。

初回に開くと「Runner」という新しいキャラクターが 1 人できています。次からは最後に開いていた キャラクターが開きます。データはブラウザ内（IndexedDB）に保存され、サーバーには残りません。

1.ルールブックと作成方式を決める（優先度タブ）

  1. セッティングのプルダウンで Chummer 同梱のプリセットを選びます。自分の Chummer の フォルダ（settings/ と customdata/ を含むフォルダ、またはその zip）を 読み込むこともできます。
  2. ルールブックを選ぶで購入対象を絞れます。チェックを外した本の項目は購入一覧に出なくなります （すでに持っている装備・資質は消えません）。1 つもチェックしなければ制限なしです。
  3. 本を手でいじるとプリセット名は外れ「カスタム」になります。設定の数値（ハウスルール）は残ります。

作成方式は 4 つ

方式 内容
優先度 標準。A〜E を 5 項目に 1 つずつ割り当てます（SR5 p.65）
Sum to Ten 同じ表で、A=4／B=3／C=2／D=1／E=0 の合計がちょうど 10 になるように（重複可）
Karma 表を使わず、すべてを 800 カルマで購入します（SR5 p.94）
ライフモジュール Run Faster の経歴を積み上げます（試験対応）

優先度／Sum to Ten では表のセルをクリックして割り当てます。Karma とライフモジュールでは代わりに タレント（Mundane／Magician／Technomancer など）をプルダウンで選びます。 余ったカルマは同じタブのスライダーで新円に替えられます（作成中のみ・逆方向には戻せません）。

2.メタタイプを決める

選んだ種族が持つ資質は「固定」として表示され、削除できません（サンプルのオークなら 低光量視野がこれに当たります）。

3.能力値を割り振る

最低値までは無料で、超えた分に能力値点を使います。EDG・MAG・RES は特殊能力値点から出ます。 余っていればチェックタブが指摘します。

4.技能を取る

  • 技能: レーティングがテストのダイス数（＋関連能力値）になります。
  • 技能グループ: グループ点で一括して上げます。中の 1 つだけを上げたり専門化を取ると グループとしては扱えなくなります。
  • 専門化: その用途のテストに +2 ダイス。優先度／Sum to Ten の作成時は技能点 1 点で取得でき、カルマでの購入も選べます。
  • 知識技能: 無料枠は (INT + LOG) × 2 点。母語が 1 つ無料になります。

5.資質を取る

有利な資質はカルマを払い、不利な資質はカルマを戻します（戻せる上限があります）。 資質によっては対象の指定が必要です（アレルギーの対象、依存症の物質、技能グループなど）。その欄は資質の行の中に出ます。 前提を満たしていない資質は理由付きで購入できません。

6.ウェアと装備を買う

作成時は入手値が上限（画面では「入手制限」。標準 12）を超える品物を買えません。残り新円と上限は装備タブの先頭と サイドバーに出ています。

7.人脈と残りのタブ

魔法／共振系のタブ（アデプト・呪文・精霊・収束具・複合体・スプライト・イニシエーション・サブマージョン）は、 タレントや資質でそのキャラクターに関係するときだけタブの列に出ます。

8.チェックタブで仕上げる

使い残した点数（能力値点・技能点・カルマ・新円）もここに出ます。 「作成ルール上の問題は見つかりませんでした」になれば完成です。

9.完成させて遊ぶ

キャリアモードへ

作成完了（キャリア）でキャリアモードに切り替わります。以降はカルマと新円で成長し、資質に払うカルマも 変わります（SR5 p.107）。エラーが残っていても確認の上で進めることはできます。同じボタンで作成モードに戻せます。

書き出しと共有

  • JSON: このアプリのバックアップ。「読込」でそのまま戻せます。
  • .chum5: Chummer 向けの保存形式。ライフモジュールは対応設定と手順書を含む ZIP で出力します。本体での実動作互換は未検証なので、JSON バックアップも保管してください。
  • .xlsx / Foundry VTT / ココフォリア / ユドナリウム / チャットパレット。
  • 共有リンク: 読み取り専用の URL。キャラクターは URL のフラグメントに入り、サーバーには送られません。

困ったときに

  • 値の横の ? を押すと計算式と内訳が出ます（ホバー・キーボード操作・タップに対応）。
  • 元に戻す / やり直し は Ctrl/⌘+Z と Ctrl/⌘+Shift+Z。
  • UI の言語は右上で切り替えます。基準は日本語です。
  • 既存のキャラクターは「読込 (JSON/.chum5/.xlsx)」から取り込めます。
  • キャラクターはブラウザ内に保存されます。別の端末へ移すときは JSON を書き出してください。
