Chummer Web 利用マニュアル

ブラウザだけで動く Shadowrun 5th Edition のキャラクター作成ツールです。このページは どの画面で何をするかを、実際の画面のスクリーンショットと一緒に順に説明します。 ルールそのものの解説ではありません（出典は画面の「?」と各項目の SR5 p.xx 表記を参照）。

掲載している画面は、このマニュアル用に作ったオークのサンプル「カイト」のものです。 魔法・共振・A.I.・クリッターのタブだけは、そのタブが出る別のサンプル（アヤ・レン・ゴースト・ジャック）で撮っています。 本文と画面は v0.5.13 の後の開発版（2026年10月23日撮影）の表記に合わせています。 数値は操作説明用のサンプルで、作成完了済みのキャラクターではありません。

画面の見取り図

画面は上からツールバー・タブの列・作業領域の 3 段で、 右（狭い画面では下）にサイドバーが常に出ています。

初回に開くと「Runner」という新しいキャラクターが 1 人できています。次からは最後に開いていた キャラクターが開きます。データはブラウザ内（IndexedDB）に保存され、サーバーには残りません。

1.ルールブックと作成方式を決める（優先度タブ）

  1. セッティングのプルダウンで Chummer 同梱のプリセットを選びます。自分の Chummer の フォルダ（settings/ と customdata/ を含むフォルダ、またはその zip）を 読み込むこともできます。
  2. ルールブックを選ぶで購入対象を絞れます。チェックを外した本の項目は購入一覧に出なくなります （すでに持っている装備・資質は消えません）。1 つもチェックしなければ制限なしです。
  3. 本を手でいじるとプリセット名は外れ「カスタム」になります。設定の数値（ハウスルール）は残ります。

卓のセッティングを使う

Chummer で卓のハウスルールを作ってある場合は、そのセッティングを読み込めます。ファイルはこのブラウザに残り、サーバーには送られません （カスタムデータは、結合した結果だけが計算のために一時的に置かれます）。

  • セッティングを読み込む: Chummer の settings/ にある .xml を 1 つ選びます。settings/ と customdata/ を固めた .zip も読めます（フォルダを選べない Android などはこちら）。
  • スタイル一式を読み込む: settings/ と customdata/ が並んだフォルダを、フォルダごと選びます。中のセッティングはすべてプルダウンの「読み込んだファイル」に入り、選んだものに合わせてカスタムデータ（追加の資質・装備など）が結合されます。
  • セッティングがカスタムデータを使っているのに .xml だけを読んだ場合は、警告が出ます。読み込むまで、カスタムデータによる追加・変更は効きません。警告の中の customdata ごと読み込むからフォルダを選び直してください。
  • このアプリが扱えないハウスルールがあると、その一覧が出ます。そこに挙がった項目は、数値や選択肢が Chummer と食い違います。
  • 読み込んだセッティングはこのセッティングを削除でブラウザから消せます。キャラクターは消えません。

作成方式は 4 つ

方式 内容
優先度 標準。A〜E を 5 項目に 1 つずつ割り当てます（SR5 p.65）
Sum to Ten 同じ表で、A=4／B=3／C=2／D=1／E=0 の合計がちょうど 10 になるように（重複可）
Karma 表を使わず、すべてを 800 カルマで購入します（SR5 p.94）
ライフモジュール Run Faster の経歴を積み上げます（試験対応）

優先度／Sum to Ten では表のセルをクリックして割り当てます。Karma とライフモジュールでは代わりに タレント（マンディン／魔法使い／テクノマンサー など）をプルダウンで選びます。 余ったカルマは同じタブのスライダーで新円に替えられます（作成中のみ・逆方向には戻せません）。

2.メタタイプを決める

選んだ種族が持つ資質は「固定」として表示され、削除できません（サンプルのオークなら 低光量視野がこれに当たります）。

一部の種族は、その本をルールブックで有効にしたときだけ候補に出ます。

  • Centaur・シェイプシフター: RF（Phocine は SAG）。シェイプシフターは動物の種類を選んだあと、 「人間形態」で人の姿を選びます。人間形態の能力値は能力値タブとシートに並べて出ます。
  • A.I.（E-Ghost・Xenosapient・Protosapient を含む）: DT。肉体能力値はなく、 タレントは A.I. のものに決まります。資質は種族の一覧にあるものだけが選べます。

3.能力値を割り振る

最低値までは無料で、超えた分に能力値点を使います。EDG・MAG・RES は特殊能力値点から出ます。 余っていればチェックタブが指摘します。

4.技能を取る

  • 技能: レーティングがテストのダイス数（＋関連能力値）になります。
  • 技能グループ: グループ点で一括して上げます。中の 1 つだけを上げたり専門化を取ると グループとしては扱えなくなります。
  • 専門化: その用途のテストに +2 ダイス。優先度／Sum to Ten の作成時は技能点 1 点で取得でき、カルマでの購入も選べます。
  • 知識技能: 無料枠は (INT + LOG) × 2 点。母語が 1 つ無料になります。

5.資質を取る

有利な資質はカルマを払い、不利な資質はカルマを戻します（戻せる上限があります）。 資質によっては対象の指定が必要です（アレルギーの対象、依存症の物質、技能グループなど）。その欄は資質の行の中に出ます。 前提を満たしていない資質は理由付きで購入できません。

6.ウェアと装備を買う

作成時は入手値が上限（画面では「入手制限」。標準 12）を超える品物を買えません。残り新円と上限は装備タブの先頭と サイドバーに出ています。

7.人脈と格闘技

魔法と共振のタブ

呪文

優先度で決まった無料枠を超えた分はカルマで買います。儀式とエンチャント（錬金術など）も同じ無料枠から取ります。

A.I. とクリッターのタブ

プログラム（A.I.）

Protosapient の Inherent Program のように資質で決まるプログラムは、資質タブで選ぶと無料で並びます。 Home Node は、装備タブのコムリンク・サイバーデッキ・RCC・ヴィークル・ドローンの行で指定します。

クリッター・パワー

種族や資質が最初から持つパワーはメタタイプタブに「固定」として出るもので、このタブでは買いません。 Infected の資質は高いので、サンプルは Karma 方式で作っています。

8.チェックタブで仕上げる

使い残した点数（能力値点・技能点・カルマ・新円）もここに出ます。 「作成ルール上の問題は見つかりませんでした」になれば完成です。

9.完成させて遊ぶ

キャリアモードへ

ツールバーの作成完了（キャリア）でキャリアモードに切り替わります。ボタンの表示は「キャリア中」になります。エラーが残っていても、確認のうえで進めます。 切り替えた時点の能力値・技能・資質・持ち物が記録され、それより後の変更はすべてカルマと新円で支払う成長として数えます。

  1. 報酬を足す: サイドバーの「ラベル」（ラン名など）と K（カルマ）・¥（新円）を入れて 報酬を追加。1 行ずつ残るので、どのランで何を得たか後から辿れます。間違えた行は「削除」で消せます。
  2. 成長させる: 能力値・技能・資質・装備のタブで、作成時と同じように値を上げたり品目を買ったりします。 払うのは点数ではなくカルマと新円です。能力値は上げた後の値 ×5 カルマです（SR5 p.107）。
  3. 内訳を見る: 成長／買い物の内訳を押すと、カルマ消費と新円消費が 1 行ずつ出ます。 残りはサイドバーの「カルマ」と「新円」です。
  • 資質: キャリアで取る有利な資質は 2 倍のカルマです。不利な資質を外すとき（買い戻し）も、得たカルマの 2 倍を払います（SR5 p.107）。キャリアで不利な資質を取ってもカルマは入りません。資質タブの各行に、キャリアで要るカルマが出ます。
  • 魔力・共振力: ウェアでエッセンスが減っている場合、上げるのに要るカルマはエッセンスで下がった後の値から決まります。 1 段ずつ、上げた時点の減り方で計算します。
  • ストリートの評判: 得たカルマの合計から計算されます。GM が別に与えた分は「SC 補正」に入れます。 「SC を 2 燃やす」で悪名を 1 減らせます（SR5 p.373）。
  • セッティングが割り増しを決めている場合、キャリアで買った入手値 R・F の品目には割り増しが付きます。作成時に買った分には付きません。
  • 残カルマ→新円のスライダーは作成中だけです。キャリアでは使えません。

「キャリア中」をもう一度押すと作成モードに戻ります。このとき、切り替えた時点の記録は消えます。 もう一度キャリアに入ると、その時点の値が新しい起点になり、それまでの成長はカルマを払わなかった扱いになります。 間違えて押したときは元に戻す（Ctrl/⌘+Z）で戻してください。

書き出しと共有

  • JSON: このアプリのバックアップ。「読込」でそのまま戻せます。
  • .chum5: Chummer 向けの保存形式。ライフモジュールは対応設定と手順書を含む ZIP で出力します。本体での実動作互換は未検証なので、JSON バックアップも保管してください。
  • .xlsx / Foundry VTT / ココフォリア / ユドナリウム / チャットパレット。
  • 共有リンク: 読み取り専用の URL。キャラクターは URL のフラグメントに入り、サーバーには送られません。

困ったときに

  • 値の横の ? を押すと計算式と内訳が出ます（ホバー・キーボード操作・タップに対応）。
  • 元に戻す / やり直し は Ctrl/⌘+Z と Ctrl/⌘+Shift+Z。
  • UI の言語は右上で切り替えます。基準は日本語です。
  • 既存のキャラクターは「読込 (JSON/.chum5/.xlsx)」から取り込めます。
  • キャラクターはブラウザ内に保存されます。別の端末へ移すときは JSON を書き出してください。
