- **Google スプレッドシート URL からの取り込みに、他の取り込みとは別の、より厳しいレート制限をかけた。** この経路だけはサーバーから外（`docs.google.com`）へ HTTPS を出すので、制限が緩いと「他人のサーバーに代わりに取りに行かせる中継」として使えてしまいます。1 人あたり `SHEET_URL_RATE_LIMIT`（既定 5/分）と、全員で共有する `SHEET_URL_TOTAL_RATE_LIMIT`（既定 60/分）の二段構えです。後者があるのは、1 人あたりの制限が IP ごとの数え方なので、多数のアドレスを持つ相手には効かないからです。制限にかかったときは取りに行く前に断り、「少し待つか、.xlsx で保存したファイルを選ぶ」と伝えます。
