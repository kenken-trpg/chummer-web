- **カスタムデータで足した品目を含む Chummer のセーブも、品目を残したまま取り込めるようにしました**：Chummer のセーブには、使った設定ファイルの名前しか入っておらず、その設定がどのカスタムデータを使うかは入っていません。そのため、カスタムデータの品目は「カタログに無い」として飛ばされていました。このブラウザで同じ名前のセッティングと、その settings と customdata が入ったフォルダを読み込んだことがあれば、そのカスタムデータを使って読み直すようにしました。読み込んだことがなければ、取り込みの報告に、どのセッティングのフォルダを読み込めばよいかを出します。
