- **CSP 違反レポートがどのデプロイでも届いていなかったのを直した。** Next が返す `Reporting-Endpoints` は絶対 URL を載せる必要があるのに、コンテナの内側から見えるオリジンは Caddy が proxy 先にしている `127.0.0.1:3000` だけで、本番のレスポンスが `csp="http://localhost:3000/api/csp-report"` を返していました。ブラウザから到達できないので、レポートは一通も送信されていません。公開オリジンは `X-Forwarded-Host` から組むようにし、Caddy と Cloudflare Worker の両方がそのヘッダを（通過させるのではなく）上書きで付けるようにしました。どちらも置けない構成向けに `PUBLIC_ORIGIN` も読みます。値はレスポンスヘッダに入るため、ホスト名以外の形は受け付けません。
