# Role&Roll のデータ

Role&Roll（ロール＆ロール）は日本の TRPG 雑誌です。号によっては、日本語版の無い SR5 サプリの一部が公式のライセンスで訳されています。
このアプリでは各号を 1 冊の本（`RR213`〜`RR241`）として扱います。本で選べるものはコデックス（`backend/app/data_loader/codex.py`）と同じで、Chummer に元からある品目の再録先です。

- 号にチェックを入れると、元のサプリがオフでも、その号が訳した品目を選べます。
- 号にチェックを入れている間だけ、その号の訳語を日本語で表示します。コデックスと違い、全体の訳の表には入れません（下の「訳語の優先順位」）。

コードは `backend/app/data_loader/role_and_roll.py` です。

## 訳語の優先順位

日本語表示での名前（frontend の `makeTr`）は、次の順に引きます。

1. チェックしている号の訳語。複数の号に載っていれば、新しい号のものを使います。本を 1 冊もチェックしていないキャラクター（制限なし）では、全部の号が対象です。
2. 全体の訳の表（日本語版の訳、上流の有志訳、自前の訳、コデックス）。

ただし、**コデックスにも載っている品目は、号の訳語を使わずコデックスの名前のままにします**（`role_and_roll.book_translations`）。号を再録先としてページを示すのは変わりません。

## 画面

設定のルールブック一覧の末尾に「Role&Roll (チェック数/号数)」として畳んで表示し、開くと各号のチェック欄が出ます（`BookChecklist`、`BookInfo.group`）。一覧に出るのは、`id` の入った行が 1 つ以上ある号だけです（`role_and_roll.books`）。データの無い号は、最初の行が入った時点で現れます。「全部オン」には号も含みます。日本語環境のプリセットには含みません。

## 入力ファイル

`backend/data/role_and_roll/entries.tsv` に、全号を 1 つの表として入力します。タブ区切り、UTF-8 です。表計算ソフトで編集して TSV で書き出しても構いません。

| 列 | 中身 |
|---|---|
| `URL` | 出版社がその号を紹介しているページ。ゲームのデータの参照先ではありません。同じ号の行は同じ URL にします。 |
| `vol.` | 号数（`215`。`vol.215` と書いても読めます）。213〜241 のどれかです。 |
| `頁` | 誌面のページ。 |
| `出典原書` | 元の英語サプリ。略号（`CF`）でも英語の書名（`Chrome Flesh`）でも構いません。誌面に無ければ空のままにします。英語名がわかる行は、スクリプトが埋めます。 |
| `分類` | 下の表の語。候補を絞るのに使います。表に無い語を書くと、全部の区分から探します。 |
| `和訳名` | 誌面の訳語。 |
| `英語（わかれば）` | 元の英語名。わからなければ空のままにします。 |
| `備考` | 自由に書けます。 |
| `id` | Chummer の id。スクリプトが埋めるので、手で書く必要はありません。1 行で複数の id（大きさ違いなど）を持つ場合は空白で区切ります。 |

**`id` が空の行は入力途中として扱い、何にも反映しません。** 書きかけのままコミットして構いません。

分類に使える語（`CATEGORIES`）：資質・武器・武器改造・防具・サイバーウェア・バイオウェア・装備・ドラッグ・呪文・アデプトパワー・メタマジック・エコー・複合体・プログラム・ヴィークル・ヴィークル改造・格闘技・メンター・伝統・ライフスタイル・メタタイプ・クリッターパワー

## 手順

1. 誌面を見て、`URL` から `備考` までを入力します。英語名がわからなければ空のままにします。
2. id を探します。

   ```
   cd backend && .venv/bin/python scripts/rr_resolve.py
   ```

   - 英語名がある行：その出典原書・分類の中で、同じ名前の品目を探します。
     - 出典原書が空なら全部の本から探し、見つかった本で出典原書を埋めます。
     - 2 冊以上の本に同じ名前があるときは埋めずに知らせるので、出典原書を書きます。
     - シェイプシフターの人間の姿（メタヴァリアントと同じ名前で、シェイプシフターごとに 1 件ずつある）は候補に入れません。
   - 英語名が無い行：候補を一覧にします（出典原書も空だと探せないので、どちらかを書くよう知らせます）。今の訳（`[…]`）が和訳名と同じ品目を先頭に出します。正しいものの英語名を行に書き写して、もう一度実行します。
   - 候補が多すぎるときは、`分類` を書くか、本ごとの一覧を見ます。

     ```
     .venv/bin/python scripts/rr_resolve.py --list CF --category サイバーウェア
     ```
3. 結果に問題が無ければ、`--write` を付けて実行し、id を書き込みます。
4. 検査は `make test`（`tests/test_role_and_roll.py`）でも行います。見つかる誤りは次のとおりです。
   - 存在しない id、出典原書と違う本の id、英語名と違う名前の id
   - 同じ号の中での重複
   - 範囲外の号数、同じ号で URL が食い違うもの

## 新しい号が出たら

`role_and_roll.py` の `LAST_ISSUE` を上げます。
