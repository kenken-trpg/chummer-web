# Role&Roll のデータ

Role&Roll（ロール＆ロール）は日本の TRPG 雑誌です。号によっては、日本語版の無い SR5 サプリの一部が公式のライセンスで訳されています。
このアプリでは各号を 1 冊の本（`RR210`〜`RR241`）として扱います。本で選べるものはコデックス（`backend/app/data_loader/codex.py`）と同じで、Chummer に元からある品目の再録先です。

- 号にチェックを入れると、元のサプリがオフでも、その号が訳した品目を選べます。
- 号にチェックを入れている間だけ、その号の訳語を日本語で表示します。コデックスと違い、全体の訳の表には入れません（下の「訳語の優先順位」）。

コードは `backend/app/data_loader/role_and_roll.py` です。

## Vol.210〜229 の掲載リストによる補完

西上柾氏の[『シャドウラン 5th Edition』Role&Roll誌掲載翻訳データリスト（Vol.210～229）](https://note.com/sheol0x01/n/n392340c92c43)をもとに、掲載された全192項目を照合しました。対象は Vol.210〜214・217〜229 の18号です。Vol.215・216 はこの資料に掲載されていません。

154項目は既存カタログの品目に対応付けています。複数のサイズ・段階・改造対象がある項目は品目ごとに登録するため、この範囲の既存登録を含む TSV の有効行は192行です。資料と Chummer で英語名が異なる場合は、Chummer の正式な品目名を `英語（わかれば）` に使い、資料の表記を `備考` に残します（例：`Sleepwaker` → `Sleepwalker`、`Healthy Grow` → `Healthy Glow`）。

資料にページ番号はないため、追加行の `頁` は空です。既に誌面から登録していた Vol.224・228 のページ番号と訳語、Vol.229 のオニ・コロボックルは保持しています。このため、既存登録の「大召霊術門」「自壊」などは資料の「大召霊術」「自爆」と異なります。

残る38項目は、ルール解説・見出し、または現行カタログに対応する選択データのない項目です。`id` を空にして掲載項目と理由を記録し、選択肢や計算には反映しません。掲載リストはルール本文や数値を含まないため、これらのルール自体を新たに実装する根拠にはしていません。

## Vol.230・231 の掲載リストによる補完

同氏の[『シャドウラン 5th Edition』Role&Roll誌掲載翻訳データリスト（Vol.230~）](https://note.com/sheol0x01/n/n743c7d1fe54d)をもとに、Vol.230 の『Chrome Flesh』8項目と Vol.231 の『Kill Code』8項目を追加しました。全16項目が既存カタログに対応しています。

フチ・サイバー N/EX シリーズは `Fuchi Cyber-N` と `Fuchi Cyber-Ex` の2行に分割し、名称でも機種を区別します。ファジー・グレネードは `Grenade: Fuzzy Boom Boom Bunnies` の装備・武器の両データに対応付けています。別項目の `Ammo: Fuzzy` は追加対象に含めません。その他、`Zapper Rounds` → `Ammo: Zapper`、`Looper Rounds` → `Ammo: Looper`、MOS の略称省略といった表記差を備考に記録しています。追加は17行・18 IDです。

## Vol.211〜241 の誌面リストによる補完

誌面を見て作った掲載リスト（号・頁・出典原書・分類・和訳名）をもとに、次の2点を行いました。英語名と id は Chummer のデータから引いています。

- **Vol.211〜231 の既存行に頁を入れました。** 和訳名が掲載リストと違う行は誌面の訳語に直し、掲載リストの訳語を `備考` に残しています（例：「賦活術」→「瞬活術」、「煙霧分身」→「煙幕分身」、「パワー貸与」→「パワー付与」）。誌面リストに無い既存行（Vol.212 の全行、Vol.221 の LCD のクリッターパワーなど）は頁が空のままです。
- **Vol.232〜241 を追加しました。** 誌面の 1 項目が Chummer で段階や対象ごとに分かれている資質は、1 品目 1 行にして和訳名に括弧で足しています（恐怖症 6 行、自制心不足：強迫行動 12 行、色度欠乏・快適さの虜・精霊狩り・死をもたらす者）。Vol.218 の割り込み動作と「門と道」の解説、Vol.232 の体得資質は、対応する選択データが無いので `id` を空にしています。

全体では30号・372行（対応付け済み329行、未対応43行）です。

## 訳語の優先順位

日本語表示での名前（frontend の `makeTr`）は、次の順に引きます。

1. チェックしている号の訳語。複数の号に載っていれば、新しい号のものを使います。本を 1 冊もチェックしていないキャラクター（制限なし）では、全部の号が対象です。
2. 全体の訳の表（日本語版の訳、上流の有志訳、自前の訳、コデックス）。

ただし、**コデックスにも載っている品目は、号の訳語を使わずコデックスの名前のままにします**（`role_and_roll.book_translations`）。号を再録先としてページを示すのは変わりません。

## 画面

設定のルールブック一覧の末尾に「Role&Roll (チェック数/号数)」として畳んで表示し、開くと各号のチェック欄が出ます（`BookChecklist`、`BookInfo.group`）。一覧に出るのは、`id` の入った行が 1 つ以上ある号だけです（`role_and_roll.books`）。データの無い号は、最初の行が入った時点で現れます。「全部オン」には号も含みます。日本語環境のプリセットには含みません。

## 入力ファイル

`backend/data/role_and_roll/entries.tsv` に、全号を 1 つの表として入力します。タブ区切り、UTF-8 です。表計算ソフトで編集して TSV で書き出しても構いません。

| 列 | 中身 |
|---|---|
| `URL` | 出版社がその号を紹介しているページ。掲載内容の資料 URL は `備考` に記録します。同じ号の行は同じ URL にします。 |
| `vol.` | 号数（`215`。`vol.215` と書いても読めます）。210〜241 のどれかです。 |
| `頁` | 誌面のページ。 |
| `出典原書` | 元の英語サプリ。略号（`CF`）でも英語の書名（`Chrome Flesh`）でも構いません。誌面に無ければ空のままにします。英語名がわかる行は、スクリプトが埋めます。 |
| `分類` | 下の表の語。候補を絞るのに使います。表に無い語を書くと、全部の区分から探します。 |
| `和訳名` | 誌面の訳語。 |
| `英語（わかれば）` | 元の英語名。わからなければ空のままにします。 |
| `備考` | 自由に書けます。 |
| `id` | Chummer の id。スクリプトが埋めるので、手で書く必要はありません。1 行で複数の id（大きさ違いなど）を持つ場合は空白で区切ります。 |

**`id` が空の行は入力途中として扱い、何にも反映しません。** 書きかけのままコミットして構いません。

分類に使える語（`CATEGORIES`）：資質・武器・武器改造・防具・サイバーウェア・バイオウェア・装備・ドラッグ・呪文・アデプトパワー・メタマジック・エコー・複合体・プログラム・ヴィークル・ヴィークル改造・格闘技・メンター・伝統・ライフスタイル・メタタイプ・クリッターパワー・精霊

## 手順

1. 誌面を見て、`URL` から `備考` までを入力します。英語名がわからなければ空のままにします。
2. id を探します。

   ```
   cd backend && .venv/bin/python scripts/rr_resolve.py
   ```

   - 英語名がある行：その出典原書・分類の中で、同じ名前の品目を探します。
     - 出典原書が空なら全部の本から探し、見つかった本で出典原書を埋めます。
     - 2 冊以上の本に同じ名前があるときは埋めずに知らせるので、出典原書を書きます。
     - シェイプシフターの人間の姿（メタヴァリアントと同じ名前で、シェイプシフターごとに 1 件ずつある）は候補に入れません。
   - 英語名が無い行：候補を一覧にします（出典原書も空だと探せないので、どちらかを書くよう知らせます）。今の訳（`[…]`）が和訳名と同じ品目を先頭に出します。正しいものの英語名を行に書き写して、もう一度実行します。
   - 候補が多すぎるときは、`分類` を書くか、本ごとの一覧を見ます。

     ```
     .venv/bin/python scripts/rr_resolve.py --list CF --category サイバーウェア
     ```
3. 結果に問題が無ければ、`--write` を付けて実行し、id を書き込みます。
4. 検査は `make test`（`tests/test_role_and_roll.py`）でも行います。見つかる誤りは次のとおりです。
   - 存在しない id、出典原書と違う本の id、英語名と違う名前の id
   - 同じ号の中での重複
   - 範囲外の号数、同じ号で URL が食い違うもの

## 新しい号が出たら

`role_and_roll.py` の `LAST_ISSUE` を上げます。
