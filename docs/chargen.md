# キャラクター作成の手順

このアプリで 1 人のランナーを作り終えるまでの流れです。シャドウラン 5th Edition の
ルールそのものの説明ではなく、**どの画面で何をするか**を書いています。ルールの出典は
画面の「?」ボタン（計算式と内訳が出ます）と各項目の出典表記（例: `SR5 p.47`）を参照して
ください。

アプリの起動方法は [README](../README.md) を参照してください。

実際の画面を見ながら進めたいときは、スクリーンショット付きの
[利用マニュアル](https://kenken-trpg.github.io/chummer-web/)（アプリのフッター「使い方」からも開けます）もあります。

## 画面の見取り図

| 場所                 | 中身                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 上部のツールバー     | 保存済みキャラクターの切り替え、新規／複製／削除、元に戻す、読込／書き出し、印刷 |
| タブの列             | 作成の各段階。順番に進めるとちょうど 1 周します                                  |
| 右（狭い画面では下） | サイドバー。モード・作成方式・リミット・費用などの現在値が常に出ます             |

初回に開くと「Runner」という新しいキャラクターが 1 人できています。次からは最後に開いて
いたキャラクターが開きます。データは**ブラウザ内（IndexedDB）**に保存され、サーバーには
残りません。

## 1. ルールブックと作成方式を決める（優先度タブ）

「優先度」タブの一番上がセッティングの選択です。

1. **セッティング** のプルダウンで Chummer 同梱のプリセット（Standard、Prime Runner など）を
   選びます。自分の Chummer のフォルダから設定ファイルを読み込むこともできます
   （`settings/` と `customdata/` を含むフォルダ、または その zip）。
2. **ルールブックを選ぶ** で購入対象を絞れます。チェックを外した本の項目は購入一覧に出
   なくなります（すでに持っている装備・資質は消えません）。1 つもチェックしなければ制限
   なしです。
3. 本を手でいじるとプリセット名は外れ「カスタム」になります。設定の数値（ハウスルール）は
   残ります。

卓のハウスルールを Chummer で作ってある場合は、次の 2 つのボタンで読み込みます。ファイルは
ブラウザに残り、サーバーには送られません（カスタムデータは、結合した結果だけが計算のために
一時的に置かれます）。

- **セッティングを読み込む**: `settings/` の `.xml` を 1 つ、または `settings/` と
  `customdata/` を固めた `.zip`（フォルダを選べない Android などはこちら）。
- **スタイル一式を読み込む**: `settings/` と `customdata/` が並んだフォルダをフォルダごと。
  中のセッティングはすべてプルダウンに入り、選んだものに合わせてカスタムデータが結合されます。
  適用した件数と「内訳を見る」が出ます。

`.xml` だけを読んだセッティングがカスタムデータを使っていると警告が出ます。警告の
**customdata ごと読み込む** からフォルダを選び直すまで、カスタムデータの追加・変更は効きません。
このアプリが扱えないハウスルールは一覧で出ます（その項目は Chummer と食い違います）。
読み込んだセッティングは **このセッティングを削除** で消せます（キャラクターは消えません）。

続いて**作成方式**を 4 つから選びます。

| 方式             | 内容                                                                              |
| ---------------- | --------------------------------------------------------------------------------- |
| 優先度           | 標準。A〜E を 5 項目に 1 つずつ割り当てます（SR5 p.65）                           |
| Sum to Ten       | 同じ表で、A=4／B=3／C=2／D=1／E=0 の合計がちょうど 10 になるように（重複可）      |
| Karma            | 表を使わず、すべてを 800 カルマで購入します（SR5 p.94）                           |
| ライフモジュール | Run Faster の経歴を積み上げます（試験対応）。[`life-modules.md`](life-modules.md) |

優先度／Sum to Ten では表のセルをクリックして割り当てます。Karma とライフモジュールでは
代わりに**タレント**（マンディン／魔法使い／テクノマンサー など）をプルダウンで選びます。

余ったカルマは、この同じタブのスライダーで新円に替えられます。**作成中のみ**で、逆方向
には戻せません。

## 2. メタタイプを決める（メタタイプタブ）

メタタイプと種族（Metavariant）を選びます。ここで能力値の下限・上限と、種族固有の
資質・クリッター・パワーが決まります。選んだ種族が持つものは「固定」として表示され、
削除できません。

Centaur とシェイプシフターは、使用ルールブックで RF（Phocine は SAG）を有効にすると
候補に出ます。シェイプシフターは動物の種類を選んだあと、「人間形態」で人の姿（Human・Elf
など）を選びます。値段は人間形態によって違います。能力値は動物の姿の範囲で振り、人間形態の
値は能力値タブとシートに並べて出ます。能力値タブの「今の姿」で人間形態を選ぶと、
ダイスプール・リミット・コンディション・モニター・イニシアティブ・移動が人間形態の値になります
（仕組みは[シェイプシフター作成対応の開発状況](shapeshifter-chargen.md)）。

A.I.（E-Ghost・Xenosapient・Protosapient を含む）は、使用ルールブックで DT を有効にすると
候補に出ます。Priority では Heritage A〜C で選べ、タレントは A.I. のもの（Depth の開始値を決める）に
決まります。能力値点は優先度の値の半分で、肉体能力値（BOD〜STR）はありません。Depth は
特殊能力値点で上げられ、EDG の上限になります。資質は種族の一覧にあるものだけが選べます
（仕組みと未対応の範囲は [A.I. 作成対応の計画と開発状況](ai-chargen.md)）。

## 3. 能力値を割り振る（能力値タブ）

最低値までは無料で、超えた分に能力値点を使います。EDG・MAG・RES は**特殊能力値点**から
出ます。余っていればチェックタブが指摘します。

サイバーウェアなどでエッセンスが減ると、MAG・RES の下限と上限が同じだけ下がります（下限は 0 まで）。
スライダーは買った値のままで、行の右に下がった下限と上限が出ます。カルマで買った分は下がった
下限の上に積まれるので、その分安くなります。

## 4. 技能を取る（技能タブ）

- **技能**: レーティングがテストのダイス数（＋関連能力値）になります。
- **技能グループ**: グループ点で一括して上げます。中の 1 つだけを上げたり専門化を取ると
  グループとしては扱えなくなります。
- **専門化**: その用途のテストに +2 ダイス。優先度／Sum to Ten の作成時は技能点 1 点で取得でき、カルマでの購入も選べます。
- **知識技能**: 無料枠は (INT + LOG) × 2 点。母語が 1 つ無料になります。

## 5. 資質を取る（資質タブ）

有利な資質はカルマを払い、不利な資質はカルマを戻します（戻せる上限があります）。
資質によっては対象の指定が必要です（アレルギーの対象、依存症の物質、技能グループなど）。
その欄は資質の行の中に出ます。前提を満たしていない資質は理由付きで購入できません。

## 6. ウェアと装備を買う（サイバー／バイオ／装備タブ）

- **サイバー**・**バイオ**: エッセンスを削って能力を上げます。等級を上げるとエッセンスの
  消費が減り、価格と入手値が上がります。
- **装備**: 武器・防具・電子機器・サイバーデッキ・ヴィークル、そして**ライフスタイル**。資金の優先度で決まった
  開始新円から払います。
- 作成時は**入手値**が上限（標準 12）を超える品物を買えません。

## 7. 人脈と残りのタブ

- **コンタクト**: コネ値と忠実値にコンタクト値を使います。
- **格闘技**: 格闘技スタイルと技法。
- **魔法／共振系のタブ**は、タレントや資質でそのキャラクターに関係するときだけタブの列に出ます。
  代表的なタレントで出るタブは次のとおりです。

  | タレント               | 出るタブ                             |
  | ---------------------- | ------------------------------------ |
  | 魔法使い・偏位魔法使い | 呪文・精霊・収束具・イニシエーション |
  | アデプト               | アデプト・収束具・イニシエーション   |
  | ミスティック・アデプト | 上の両方                             |
  | テクノマンサー         | 複合体・スプライト・サブマージョン   |
  - **呪文**・**複合体**: 先頭で様式（呪文のみ）を選び、カタログから加えます。無料枠を
    超えた分はカルマで買います。フォース／レベルを入れるとドレイン／フェイディングの値が変わります。
  - **アデプト**: パワーポイント（PP）でパワーを買います。ミスティック・アデプトは PP をカルマで
    買い足すスライダーが出ます。「Way 割引」は Way（流儀）の資質で安くなるパワーの印です。
  - **精霊**・**スプライト**: 一覧から召喚／結合（スプライトはコンパイル／登録）で加え、
    フォース（レベル）と助力（タスク）の回数を入れます。
  - **収束具**: 「購入」は定価、「クラフト」は自作。結合に払うカルマはフォースで決まります。
    「結合する」を外すと、値段だけ払って結合していない収束具になります（効果なし、魔力の上限に数えない）。
  - **イニシエーション**・**サブマージョン**: カルマを払って等級を上げ、等級ごとにメタマジック
    （エコー）を 1 つ選びます。

- **プログラム**: A.I. のときだけ出ます。A.I. のプログラムをカルマで買います。Protosapient の
  Inherent Program のように資質で決まるプログラムは、資質タブで選ぶと無料で並びます。Home Node は
  装備タブのコムリンク・サイバーデッキ・RCC・ヴィークル・ドローンの行で指定します（仕組みは
  [A.I. 作成対応の計画と開発状況](ai-chargen.md)）。
- **クリッター・パワー**: Infected や Drake のように、資質でパワーの種類が決まるキャラクターの
  ときだけ出ます。その種類のクリッター・パワーをカルマで買います。種族が最初から持つ
  パワーはメタタイプタブに「固定」として出るもので、このタブでは買いません。
  `.chum5` の取り込みで買ったパワーが入っていたときも出ます。

## 8. チェックタブで仕上げる

「チェック」タブが作成ルール上の問題を**エラー（作成不可）／警告／情報**に分けて並べます。
各行の「該当タブへ」でその場所に飛べます。使い残した点数（能力値点・技能点・カルマ・新円）も
ここに出ます。「作成ルール上の問題は見つかりませんでした」になれば完成です。

## 9. 完成させて遊ぶ

- **作成完了（キャリア）**: 確認画面からキャリアモードに切り替えます（下の「キャリアモード」）。
- **シート**タブ: 完成したキャラクターシート。レイアウトを選んで印刷（ダイアログで
  「PDF として保存」も選べます）。
- **書き出し**: JSON（バックアップ）、`.chum5`（Chummer 本体で開く）、`.xlsx`、Foundry VTT、
  ココフォリア、ユドナリウム、チャットパレット。詳細は [`exports.md`](exports.md)。
- **共有リンク**: 読み取り専用の URL を作れます。[`share-link.md`](share-link.md)。

## キャリアモード

ツールバーの **作成完了（キャリア）** で確認画面を開き、**確認してキャリアへ移行** で切り替えます。エラーが残っていても内容を確認して進めます。
切り替えた時点の能力値・技能・資質・持ち物が記録され、それより後の変更はすべてカルマと新円で
払う成長として数えます。

1. **報酬を足す**: サイドバーの「ラベル」（ラン名など）・K・¥ を入れて **報酬を追加**。
   1 行ずつ残り、「削除」で消せます。
2. **成長させる**: 各タブで作成時と同じように値を上げ、品目を買います。払うのはカルマと新円です。
   能力値は上げた後の値 ×5 カルマです（SR5 p.107）。
3. **内訳を見る**: **成長／買い物の内訳** で、カルマ消費と新円消費が 1 行ずつ出ます。

- 資質: キャリアで取る有利な資質と、不利な資質の買い戻しは 2 倍のカルマです。キャリアで
  取った不利な資質はカルマをくれません（SR5 p.107）。
- 魔力・共振力: エッセンスが減っていると、エッセンスで下がった後の値で要るカルマが決まります
  （1 段ずつ、上げた時点の減り方で）。
- ストリートの評判: 得たカルマから計算され、GM が与えた分は「SC 補正」に入れます。
  「SC を 2 燃やす」で悪名が 1 減ります（SR5 p.373）。
- セッティングが割り増しを決めている場合、キャリアで買った入手値 R・F の品目に割り増しが付きます。
- 残カルマ→新円のスライダーは作成中だけです。
- 作成時から持っていた呪文・格闘技・フォーカスなどをキャリアで消したり、作成時にカルマで買った値を下げたりすると、
  作成時に払ったカルマが戻ります。Chummer は戻しません。資質だけは Chummer と同じく戻りません。
- キャリアで足したコンタクトにも、作成時の点を超えた分のカルマがかかります。Chummer では無料です。

「キャリア中」をもう一度押すと作成モードに戻り、切り替えた時点の記録は消えます。再びキャリアに
入るとその時点が新しい起点になり、それまでの成長はカルマを払わなかった扱いになります。間違えた
ときは **元に戻す**（`Ctrl/⌘+Z`）で戻せます。

## 困ったときに

- 値の横の **?** を押すと計算式と内訳が出ます（ホバー・キーボード操作・タップに対応）。
- **元に戻す / やり直し** は `Ctrl/⌘+Z` と `Ctrl/⌘+Shift+Z`。
- UI の言語は右上で切り替えます。基準は日本語です（[`i18n.md`](i18n.md)）。
- 既存のキャラクターは「読込 (JSON/.chum5/.xlsx)」から取り込めます。Chummer 本体が保存した
  `.chum5` の対応範囲は [README](../README.md) の「`.chum5` の取り込み」を参照してください。

## 編集履歴と取り込み結果

画面上部の「編集履歴・復元」から、現在のキャラクターの変更前の状態を選んで復元できます。
履歴は直近10件までブラウザ内に保存され、ページを開き直しても残ります。復元時は計算をやり直し、
復元前の状態も履歴に残します。キャラクターを削除すると、そのキャラクターの履歴も削除されます。
履歴はこの機能を使い始めた後の変更から記録されます。JSON や `.chum5` のバックアップとは別に保管してください。

ファイルやスプレッドシートを取り込むと、取り込んだキャラクター名と技能・資質・コンタクト・装備などの件数が表示されます。装備などのカテゴリーを開くと、品目名も確認できます。
取り込み時に移動した品目や対応できなかった項目は、同じ確認欄に警告として表示します。
警告がない場合も、その旨を表示します。確認欄は「閉じる」で閉じられます。

## バックアップの案内

画面上部の「バックアップ」で、最後にJSONを書き出した日時と、その後の変更回数を確認できます。
10回以上変更したとき、または前回のJSON書き出しから7日以上たち、その後の変更があるときに保存を案内します。
「JSONでバックアップ」を押すと、現在のキャラクターをJSONでダウンロードできます。ツールバーのJSON書き出しでも記録されます。
書き出し日時の記録は、ブラウザにダウンロードを渡した時点のものです。ダウンロードしたファイルは手元に保管してください。

日時と変更回数はキャラクターごとに、このブラウザに保存されます。初回は日時の記録がない状態で始まります。
Chummer・Excel・VTTへの書き出しや共有リンクは、このJSONバックアップの記録には含めません。

## キャラクター一覧の検索・整理

画面上部の「キャラクター一覧」を開くと、保存したキャラクターを表で確認できます。
名前の一部で検索し、「すべて／作成中／キャリア」で絞り込み、「最終更新が新しい順／名前順」で並べ替えられます。
検索では大文字・小文字、全角・半角の違いを区別しません。

一覧にはメタタイプ、作成方式、最終更新日時、未バックアップの変更の有無を表示します。
「開く」でキャラクターを切り替えられます。更新日時は入力内容が変わった時点で、開いたときの再計算やJSON書き出しでは変わりません。

## 複数キャラクターの一括バックアップ

「キャラクター一覧」を開き、「全キャラクターを一括バックアップ」を押すと、保存済みの全キャラクターを1つのJSONにまとめてダウンロードします。
検索や絞り込みにかかわらず、全員が対象です。保存中の編集があれば完了を待ってから書き出し、それぞれのJSONバックアップ日時を記録します。

通常の「取り込み」でこのJSONを開くと、ファイル内のキャラクターが一覧で出ます。チェックボックスで取り込む対象を選び、
「選択したキャラクターを取り込む」を押してください。同名のキャラクターも新しく追加し、既存のキャラクターは上書きしません。
選択した全員の読み込みと計算が成功してからまとめて保存します。読み込みや保存に失敗した場合は、その取り込みでは追加しません。

ファイルには各キャラクターの現在の状態（画像・備考・設定を含む）を入れます。編集履歴やバックアップ日時、
スプレッドシートからの取り込みでまだ確定していない装備の行は含みません。取り込んだキャラクターの編集履歴は新しく始まります。

## シート内容の検索

画面上部の「シート内容を検索」は、現在のキャラクターが所持・習得している項目や、経歴・メモを検索します。
表示中のタブにかかわらず、装備・武器・防具・ウェア・資質・呪文・パワー・技能・コンタクトなどを対象にします。
日本語名と英語名、呼び名、備考、保管場所、入れ物や機器の名前でも探せます。空白で区切った語は、すべてを含む項目を探します。
大文字・小文字、全角・半角は区別しません。購入候補のカタログ全体を探す検索とは別です。

結果には編集タブと入れ物・機器などの経路を表示します。名前のボタンを押すと該当タブと装備カテゴリーを開き、
対象の行まで移動して5秒間強調表示します。ウェアやヴィークルの簡略表示は移動時に展開し、対象の備考欄も開きます。
検索結果の備考欄からも内容を確認できます。100件を超える場合は先頭100件を表示するので、検索語を追加して絞り込んでください。

## 作成完了前の確認

「作成完了（キャリア）」を押すと、キャリアに移る前の確認画面を開きます。
能力値点・特殊能力値点・技能点・技能グループ点・知識技能点、カルマ、新円などの残りを一覧で確認できます。
キャラクターに応じて、コンタクト点、パワーポイント、無料の呪文・複合体の枠も表示します。

既存の作成チェックと同じエラー・警告・未使用枠をまとめて表示し、導師精霊などの未選択や、取り込み後に未確定の装備も知らせます。
「該当タブへ」を押すと、移行せず編集画面へ戻ります。「作成を続ける」でも取り消せます。
「確認してキャリアへ移行」を押して初めてキャリアになります。エラーが残っていても、内容を確認して移行できます。

保存途中の編集があれば完了を待ってから確認画面を開きます。確認画面を開いた後に編集やキャラクターの切り替えがあると、
その確認は取り消します。移行に失敗した場合は確認画面にエラーを表示し、再試行できます。
