# キャラクター作成の手順

このアプリで 1 人のランナーを作り終えるまでの流れです。シャドウラン 5th Edition の
ルールそのものの説明ではなく、**どの画面で何をするか**を書いています。ルールの出典は
画面の「?」ボタン（計算式と内訳が出ます）と各項目の出典表記（例: `SR5 p.47`）を参照して
ください。

アプリの起動方法は [README](../README.md) を参照してください。

実際の画面を見ながら進めたいときは、スクリーンショット付きの
[利用マニュアル](https://kenken-trpg.github.io/chummer-web/)（アプリのフッター「使い方」からも開けます）もあります。

## 画面の見取り図

| 場所                 | 中身                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 上部のツールバー     | 保存済みキャラクターの切り替え、新規／複製／削除、元に戻す、読込／書き出し、印刷 |
| タブの列             | 作成の各段階。順番に進めるとちょうど 1 周します                                  |
| 右（狭い画面では下） | サイドバー。モード・作成方式・リミット・費用などの現在値が常に出ます             |

初回に開くと「Runner」という新しいキャラクターが 1 人できています。次からは最後に開いて
いたキャラクターが開きます。データは**ブラウザ内（IndexedDB）**に保存され、サーバーには
残りません。

## 1. ルールブックと作成方式を決める（優先度タブ）

「優先度」タブの一番上がセッティングの選択です。

1. **セッティング** のプルダウンで Chummer 同梱のプリセット（Standard、Prime Runner など）を
   選びます。自分の Chummer のフォルダから設定ファイルを読み込むこともできます
   （`settings/` と `customdata/` を含むフォルダ、または その zip）。
2. **ルールブックを選ぶ** で購入対象を絞れます。チェックを外した本の項目は購入一覧に出
   なくなります（すでに持っている装備・資質は消えません）。1 つもチェックしなければ制限
   なしです。
3. 本を手でいじるとプリセット名は外れ「カスタム」になります。設定の数値（ハウスルール）は
   残ります。

続いて**作成方式**を 4 つから選びます。

| 方式             | 内容                                                                              |
| ---------------- | --------------------------------------------------------------------------------- |
| 優先度           | 標準。A〜E を 5 項目に 1 つずつ割り当てます（SR5 p.65）                           |
| Sum to Ten       | 同じ表で、A=4／B=3／C=2／D=1／E=0 の合計がちょうど 10 になるように（重複可）      |
| Karma            | 表を使わず、すべてを 800 カルマで購入します（SR5 p.94）                           |
| ライフモジュール | Run Faster の経歴を積み上げます（試験対応）。[`life-modules.md`](life-modules.md) |

優先度／Sum to Ten では表のセルをクリックして割り当てます。Karma とライフモジュールでは
代わりに**タレント**（Mundane／Magician／Technomancer など）をプルダウンで選びます。

余ったカルマは、この同じタブのスライダーで新円に替えられます。**作成中のみ**で、逆方向
には戻せません。

## 2. メタタイプを決める（メタタイプタブ）

メタタイプと種族（メタバリアント）を選びます。ここで能力値の下限・上限と、種族固有の
資質・クリッター・パワーが決まります。選んだ種族が持つものは「固定」として表示され、
削除できません。

## 3. 能力値を割り振る（能力値タブ）

最低値までは無料で、超えた分に能力値点を使います。EDG・MAG・RES は**特殊能力値点**から
出ます。余っていればチェックタブが指摘します。

## 4. 技能を取る（技能タブ）

- **技能**: レーティングがテストのダイス数（＋関連能力値）になります。
- **技能グループ**: グループ点で一括して上げます。中の 1 つだけを上げたり専門化を取ると
  グループとしては扱えなくなります。
- **専門化**: その用途のテストに +2 ダイス。優先度／Sum to Ten の作成時は技能点 1 点で取得でき、カルマでの購入も選べます。
- **知識技能**: 無料枠は (INT + LOG) × 2 点。母語が 1 つ無料になります。

## 5. 資質を取る（資質タブ）

有利な資質はカルマを払い、不利な資質はカルマを戻します（戻せる上限があります）。
資質によっては対象の指定が必要です（アレルギーの対象、依存症の物質、技能グループなど）。
その欄は資質の行の中に出ます。前提を満たしていない資質は理由付きで購入できません。

## 6. ウェアと装備を買う（サイバー／バイオ／装備タブ）

- **サイバー**・**バイオ**: エッセンスを削って能力を上げます。等級を上げるとエッセンスの
  消費が減り、価格と入手値が上がります。
- **装備**: 武器・防具・電子機器・サイバーデッキ・ヴィークル、そして**ライフスタイル**。資金の優先度で決まった
  開始新円から払います。
- 作成時は**入手値**が上限（標準 12）を超える品物を買えません。

## 7. 人脈と残りのタブ

- **コンタクト**: コネ値と忠実値にコンタクト値を使います。
- **格闘技**: 流派とテクニック。
- **魔法／共振系のタブ**（アデプト・呪文・精霊・収束具・複合体・スプライト・イニシエーション・
  サブマージョン）は、タレントや資質でそのキャラクターに関係するときだけタブの列に出ます。

## 8. チェックタブで仕上げる

「チェック」タブが作成ルール上の問題を**エラー（作成不可）／警告／情報**に分けて並べます。
各行の「該当タブへ」でその場所に飛べます。使い残した点数（能力値点・技能点・カルマ・新円）も
ここに出ます。「作成ルール上の問題は見つかりませんでした」になれば完成です。

## 9. 完成させて遊ぶ

- **作成完了（キャリア）**: キャリアモードに切り替えます。以降はカルマと新円で成長し、
  資質に払うカルマも変わります（SR5 p.107）。エラーが残っていても確認の上で進めることはできます。
  同じボタンで作成モードに戻せます。
- **シート**タブ: 完成したキャラクターシート。レイアウトを選んで印刷（ダイアログで
  「PDF として保存」も選べます）。
- **書き出し**: JSON（バックアップ）、`.chum5`（Chummer 本体で開く）、`.xlsx`、Foundry VTT、
  ココフォリア、ユドナリウム、チャットパレット。詳細は [`exports.md`](exports.md)。
- **共有リンク**: 読み取り専用の URL を作れます。[`share-link.md`](share-link.md)。

## 困ったときに

- 値の横の **?** を押すと計算式と内訳が出ます（ホバー・キーボード操作・タップに対応）。
- **元に戻す / やり直し** は `Ctrl/⌘+Z` と `Ctrl/⌘+Shift+Z`。
- UI の言語は右上で切り替えます。基準は日本語です（[`i18n.md`](i18n.md)）。
- 既存のキャラクターは「読込 (JSON/.chum5/.xlsx)」から取り込めます。Chummer 本体が保存した
  `.chum5` の対応範囲は [README](../README.md) の「`.chum5` の取り込み」を参照してください。
