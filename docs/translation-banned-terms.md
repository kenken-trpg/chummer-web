# 使ってはいけない訳語

`docs/translation-glossary.md` が正典ですが、正典との照合を機械で全自動にはできません。
日本語の文だけを見て「どの英語用語の訳か」は復元できないためです。そこで、**過去に実際に
混入した誤りだけ**をここに記録し、`scripts/check_ja_terms.py` が `frontend/lib/i18n/locales/ja/`
を走査して再発を落とします。

新しい表記のずれを直したら、ここに 1 行足してください。それ以降その語は二度と入りません。

- `誤` — 禁止する表記。部分一致で探します。
- `正` — 正典の訳語。
- `典拠` — `docs/translation-glossary.md` の行。
- `許容` — その語を含んでいても正しい語（カンマ区切り）。空欄なら例外なし。
